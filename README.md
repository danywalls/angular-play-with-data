# Sorting, Filtering, Grouping and Aggregating Data in Angular

## Project Summary
A comprehensive example of data manipulation in Angular using built-in array methods and Kendo UI for complex operations.

## How to Run
### Installation
1. `npm install` 

### Running
1. `ng serve` 
2. Use the UI controls to sort, filter, and group the dataset.
